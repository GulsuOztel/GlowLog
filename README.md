# GlowLog ✨

Cilt bakım rutini ve ürün takipçisi. Kullanıcı ürünlerini kaydeder, sabah/akşam rutinlerini oluşturur, her gün tamamladığı adımları işaretler ve cilt durumunu not eder.

## Canlı Demo

- Canlı uygulama: CANLI_URL_BURAYA
- GitHub deposu: https://github.com/GulsuOztel/GlowLog

## Özellikler

- Ürün ekleme, düzenleme, silme (yakında)
- Sabah ve akşam rutini oluşturma (yakında)
- Günlük rutin takibi (yakında)
- Günlük cilt puanı ve notu (yakında)
- Verilerin LocalStorage'da saklanması (yakında)

## Kullanılan Teknolojiler

- React
- Vite
- JavaScript (ES6+)
- CSS3 (düz CSS)
- LocalStorage
- Git ve GitHub
- Vercel (yayınlama)

## Kurulum

```bash
git clone https://github.com/GulsuOztel/GlowLog.git
cd GlowLog
npm install
npm run dev
```

Ardından tarayıcıda `http://localhost:5173` adresini açın.
